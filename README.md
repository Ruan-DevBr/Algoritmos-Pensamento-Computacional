## ▶️ Como executar os programas

1. Clone este repositório:
   ```bash
   git clone https://github.com/Ruan-DevBr/Algoritmos-Pensamento-Computacional.git
   ```

2. Acesse a pasta do exercício desejado.

3. Compile o arquivo C utilizando o GCC:
   ```bash
   gcc programa.c -o programa
   ```

4. Execute o programa:

   **Windows:**
   ```bash
   programa.exe
   ```

   **Linux:**
   ```bash
   ./programa
   ```
